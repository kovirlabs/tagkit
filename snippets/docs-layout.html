Install shipit

shipit deploys a folder of static files with one command.

Requirements

Node.js 20 or later, and an account on your host.

Install

npm install --global shipit

Check the install

shipit --version

Your first deploy

Run shipit in the folder you want to publish. Press Ctrl + C to cancel.

Tip: Add --dry-run to see what would be uploaded.
