# Configure

## Options

| Option     | Default | Meaning                              |
|:-----------|:-------:|-------------------------------------:|
| `target`   | none    | Where to upload                      |
| `exclude`  | `[]`    | Files to leave out                   |
| `parallel` | `4`     | Uploads at the same time             |

## Environment variables

Set `SHIPIT_TOKEN` to avoid typing a password.
