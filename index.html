Templates and snippets in plain HTML

Copy the HTML. TagBrush.css styles it, TagAction makes it behave, and every piece passes TagCheck.

Page templates

Complete pages. Open one, then copy its source.

  • Admin table: a page to manage records, with breadcrumbs, a title row with an action, a filter box, a sortable table with status badges, and an "invite" form in a modal dialog.
  • Blog post: an article with author and date, a lead image that enlarges, sections with anchor links, a pull quote, code with a copy button, a sortable table, a callout, and related posts.
  • Dashboard: an app page with a full-height sidebar, a top bar with an account menu, stat tiles, a sortable and filterable orders table, and a ranked list.
  • Docs page: breadcrumbs, a generated table of contents that follows the scroll, heading anchor links, code with copy buttons, a tip callout, and previous/next links.
  • Landing page: a hero with a picture, a feature grid, pricing plans, testimonials, an FAQ accordion, a call to action, and a footer with link columns.
  • Sign-up page: a single-form page with help text, a password show/hide toggle, checkboxes, a switch, a character counter, and validation messages under each field.

Snippets

Pieces to paste into a page that already links TagBrush.css (and TagAction, for the behaviors).

Callouts

highlighted notes inside an article. A bold first word labels them; data-tone colors them. Preview the callouts.

  <aside><strong>Note:</strong> Changes to variables take effect on the next deploy.</aside>
  <aside data-tone="warning"><strong>Warning:</strong> Deleting a variable can break a running site.</aside>
</article>
